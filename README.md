# 📝 Blog Management System

A **Full Stack Blog Management System** developed during the **Codomax Full Stack Development Internship**. This project enables users to create, view, edit, and delete blog posts through a clean, responsive, and user-friendly interface. It demonstrates frontend and backend integration using modern web development technologies.

---

# 🚀 Project Overview

The Blog Management System is designed to manage blog posts efficiently. Users can add new blogs, edit existing blogs, delete blogs, and browse different categories. The project also includes responsive design, form validation, REST API integration, and a contact page.

# ⚙️ Installation

Follow these steps to run the project on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/kusum25official-tech/Blog-system.git
```

### 2. Move to the Project Folder

```bash
cd Blog-system
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Backend Server

```bash
npm start
```

or

```bash
node index.js
```

### 5. Run the Frontend

Open **index.html** using **Live Server** in VS Code.

Frontend URL

```text
http://127.0.0.1:5500/index.html
```

Backend API URL

```text
http://localhost:3000/blogs
```

# ▶️ How to Use

1. Open the Home Page.
2. Click **Add Blog**.
3. Fill in the blog details.
4. Submit the form.
5. View the latest blog on the Home Page.
6. Edit or Delete existing blogs.
7. Visit the Categories, About, and Contact pages.
